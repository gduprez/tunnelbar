# Security policy / Politique de sécurité

## Reporting a vulnerability (English)

Please **do not open a public issue**. Use GitHub's private vulnerability
reporting: **Security › Report a vulnerability** on
[github.com/gduprez/tunnelbar](https://github.com/gduprez/tunnelbar/security).
You will get an answer within a week.

TunnelBar runs `ssh` with user-provided values; anything that lets a
configuration value run a command or change `ssh` options is in scope.

## Signaler une vulnérabilité (français)

Merci de **ne pas ouvrir d'issue publique**. Utilisez le signalement privé de
GitHub : **Security › Report a vulnerability** sur
[github.com/gduprez/tunnelbar](https://github.com/gduprez/tunnelbar/security).
Vous aurez une réponse sous une semaine.

TunnelBar lance `ssh` avec des valeurs fournies par l'utilisateur : tout ce qui
permet à une valeur de configuration d'exécuter une commande ou de modifier les
options de `ssh` est concerné.
